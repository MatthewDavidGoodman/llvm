# LLVM Dead-Function Analysis — Coursework Archive

Legacy compiler/program-analysis coursework exploring an LLVM module pass for call-graph construction and dead-function detection.

The source examines functions and call instructions, builds a call graph, and sketches logic for identifying functions unreachable from `main`.

## Status

Historical and incomplete coursework artifact. The code contains unfinished sections and is not presented as a production-ready LLVM pass.
